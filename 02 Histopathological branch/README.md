# 02_histopatologia

Whole-slide-image (WSI) analysis for TCGA-BRCA and the INC Bogotá validation cohort.

## Contents (currently available)

| Path | Description |
|---|---|
| `00_preprocesamiento_propio/wsi_step1_segmentation.py` | Tissue segmentation of slides (thumbnail at 4x, local-variance texture map, CLAHE, triangle threshold, morphology, pen-mark and blur removal). |
| `00_preprocesamiento_propio/wsi_step2_patch_extraction.py` | Patch extraction on a regular grid (1000 px at 40x, 500 px at 20x), quality filter, JPEG patches and `patch_info.csv` with 14 colorimetric descriptors. |
| `E1_kimianet_mosaico/01_mosaic_building.ipynb` | Approach E1: *k*-medoids selection of 16 representative patches per slide and assembly of a 4000 × 4000 px mosaic, for four distances. |
| `E1_kimianet_mosaico/02_feature_extraction.ipynb` | KimiaNet (DenseNet-121) 1024-dimensional descriptors of every mosaic. |
| `E1_kimianet_mosaico/03_experimental_design.ipynb` | Loading and inspection of the cohort tables (paired RNA-seq / WSI patients, subtype labels). |

The in-house preprocessing scripts (`00_preprocesamiento_propio`) were used for the TCGA slides that were missing from the original preprocessed set (17 slides) and for the INC Bogotá validation slides (41 slides processed, 23 finally used).

## Data flow

```
slides (*.svs)
   │  wsi_step1_segmentation.py       → <processed>/<slide>/<slide>_tissue_mask.png, thumbnail, QC overlay
   │  wsi_step2_patch_extraction.py   → <processed>/<slide>/<k>.jpg  +  patch_info.csv
   ▼
01_mosaic_building.ipynb              → 00_datos/mosaics/<distance>/<slide>.png
   ▼
02_feature_extraction.ipynb           → 00_datos/mosaics/<distance>/KimiaNet_features.csv
```

## Running the preprocessing scripts

```bash
python 00_preprocesamiento_propio/wsi_step1_segmentation.py     --wsi-dir /path/to/slides --out-dir 00_datos/wsi_processed
python 00_preprocesamiento_propio/wsi_step2_patch_extraction.py --wsi-dir /path/to/slides --out-dir 00_datos/wsi_processed
```

Both scripts must receive the same `--out-dir`. The slide identifier is the file name without extension (`--pattern` selects the files, default `*.svs`). Use the environment in `envs/requirements_wsi.txt`. The notebooks are executed from their own directory and read from / write to `00_datos/` and `resultados/` through relative paths defined in their first cells.

Expected inputs in `00_datos/` (not tracked): `wsi_processed/`, `wsi_partition_metadata.csv` (columns `IDs`, `partition`; optional, only for the choice of the number of clusters), `KimiaNet/KimiaNetKerasWeights.h5`, `gene_expression.tsv`, `subtype.tsv` and `pacientes_emparejados_1081.tsv`.

## Validation of the cleaned code

The cleaned scripts and notebooks were checked against the original code on synthetic slides: segmentation masks, thumbnails, patch JPEGs and `patch_info.csv` are byte-identical; the *k*-medoids implementation selects the same medoids; and the mosaics are pixel-identical.

## Known issues and considerations

1. **Outlier fence.** The *cell index* filter uses `Q1 + 1.5·IQR` as the upper fence, not the conventional `Q3 + 1.5·IQR`. It is kept for consistency with the mosaics generated by the original pipeline (`UPPER_FENCE_PERCENTILE` in `01_mosaic_building.ipynb`).
2. **Clustering.** *k*-medoids is an alternating algorithm with seeded random initialisation, not PAM and not the default initialisation of `sklearn_extra`.
3. **Descriptors.** `patch_info.csv` ends with `tissue_cov`, which the mosaic notebook includes in the descriptor vector (all columns after the first two).
4. **Heterogeneous preprocessing.** Slides processed by the in-house scripts and by the original pipeline may differ in the definition of the descriptors and of the *cell index*.
5. **Duplicated identifiers.** Slide folders whose identifier is longer than 12 characters, or that share a patient barcode with another slide, are reported by Section 4.1 of `01_mosaic_building.ipynb`.
